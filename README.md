# Système RH – Gestion des Ressources Humaines

Application web de gestion des ressources humaines développée avec ASP.NET MVC (C#) et Entity Framework.

## Fonctionnalités

- Gestion des employés, départements et postes
- Gestion des contrats de travail
- Gestion des congés (demandes et suivi)
- Authentification et gestion des comptes utilisateurs

## Stack technique

- ASP.NET MVC, C# (.NET)
- Entity Framework (migrations incluses)
- Razor Views

## Lancer le projet

1. Ouvrir la solution dans Visual Studio
2. Configurer la chaîne de connexion dans `appsettings.json`
3. Appliquer les migrations Entity Framework (`Update-Database`)
4. Lancer le projet (F5)

## Contexte

Projet réalisé pour s'exercer au développement d'applications de gestion en ASP.NET MVC / C#.
